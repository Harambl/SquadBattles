# Бои отрядов

Пентяшкин Алексей Сергеевич\
Б9124-02.03.01мо

Небольшая игра про сражение двух отрядов.\
У каждого есть возможность атаковать, защищаться и использовать спецприем.\
На данный момент в игре существует три класса.\
Лучник пробивает блок, воин становится неуязвимым на 1 ход, маг проводит атаку которая, наносит урон всем врагам.\
Ограничение на спецприем - 2 использования.\

В начале игрока встречает приветственный экран.

Затем по нажатию кнопки он переходит в меню подготовки перед боем и там ему 
представлен его отряд(на данный момент его выбирать нужно случайным образом), 
а также можно выбрать отряд врага из заготовленных пресетов.

Как только отряд собран можно начинать бой. Игрок переходит на экран боя где
и происходит само сражение с использованием кнопок атаковать, защищаться и 
особого умения, а также кнопка смены действующего героя у данного отряда.

По завершении боя выводиться окно с результатом и кнопкой которая возвращает в меню подготовки.
